# 最寄り駅フィルタ（私鉄除外）

心斎橋通勤向けに、**SUUMO 一覧の最寄り1行目（太字）** で物件を絞る。

## ルール

1. **DENY 優先** — 1行目に `近鉄` `阪急` `阪神` `南海` 等 → 除外  
2. **ALLOW 必須** — 1行目に `地下鉄` `御堂筋` `千日前` `長堀` `ＪＲ` 等のいずれか  
3. どちらも該当しない → 除外  

詳細ページ取得後、**詳細の駅徒歩1行目**でも再チェック（一覧と食い違う場合は落とす）。

## 環境変数

| 変数 | 説明 |
|------|------|
| `ACCESS_FILTER` | `false` で無効（デフォルト有効） |

## state について

フィルタ後の ID だけを state に保存する。フィルタ導入直後は、除外物件が「新規」として誤検知しない（もともと state に無いため）。

逆に、以前 state に入っていた ID がフィルタで落ちると、state から消える（次回以降その ID が再掲載されたら新規扱い）。許容範囲。
